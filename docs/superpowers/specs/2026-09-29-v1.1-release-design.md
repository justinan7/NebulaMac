# NebulaMac v1.1.0 — signed release, Settings redesign, docs

## Goal

A new user can download NebulaMac (DMG, Homebrew or Nix), open it without Gatekeeper warnings,
and get a mesh connected by following a short README. Settings looks like a native macOS app and
uses the swirl identity everywhere.

## 1. Settings and icon

### Settings window

Native tabbed `Settings` scene (`TabView` with `.tabItem`), one file per tab under
`NebulaMac/Views/Settings/`:

| Tab | Contents |
|-----|----------|
| **Networks** (first) | One row per mesh: status dot, name, cert IP, cert expiry, lighthouse, `MeshToggle`. Config warnings under the row. "Rescan configs" button. Empty state points to the README. |
| **General** | Auto-connect on launch, Launch at login, Notifications, Menu bar icon style. |
| **Advanced** | `nebula` path, `nebula-cert` path, config directory, poll interval, passwordless setup (status + copyable command + recheck). |

Visual rules:
- `Form` + `.formStyle(.grouped)`, plain section headers (no icons, no per-section tints).
- No custom `.tint`; controls use the system accent.
- Orange/red only for real problems (missing binary, cert < 30 days / expired, config warnings).
- Remove the header status pill.
- Footer on every tab: small swirl (same renderer as the menu bar), `NebulaMac <CFBundleShortVersionString>`, `Nebula <version>` from the *configured* `nebulaPath`, computed once off the main thread.

`SwirlIconRenderer` gains a size parameter so the footer can draw it larger than 18 pt.

### App icon

`scripts/generate_icon.swift` is rewritten: near-black/deep-navy squircle, white swirl built from
`SwirlGeometry` (all arms on, core lit), soft glow on the core only. Regenerates the PNGs in
`AppIcon.appiconset`. The script compiles together with `NebulaMacCore/Swirl.swift` so the geometry
is shared, not copied.

### Binary auto-detection

New `NebulaMacCore/BinaryLocator.swift`: given a binary name and an `isExecutable` predicate, returns
the first match in `/opt/homebrew/bin`, `/usr/local/bin`, `~/.nix-profile/bin`,
`/run/current-system/sw/bin`. On launch, if the stored `nebulaPath` / `nebulaCertPath` isn't
executable, it's replaced with the detected one. User-set valid paths are never overwritten.

### Small fixes
- Version comes from the bundle (was hard-coded `v1.0.0`).
- Nebula version uses the configured path (was hard-coded `/usr/local/bin/nebula`).
- Drop `.process("Assets.xcassets")` from `Package.swift`: nothing reads `Bundle.module`, and the
  Makefile builds the `.icns` from the PNGs with `iconutil`. Removes the full-Xcode requirement.
  The unused `MenuBarIcon.imageset` is deleted.

## 2. Release

`CFBundleShortVersionString` / `CFBundleVersion` → `1.1.0`.

### Makefile targets

- `make bundle` — as today, but builds universal (`--arch arm64 --arch x86_64`) and copies
  `scripts/install-sudoers.sh` into `Contents/Resources/`.
- `make release` — `bundle`, then:
  1. `codesign --force --options runtime --timestamp --sign "Developer ID Application: …"` (identity
     overridable via `SIGN_ID`).
  2. Zip with `ditto -c -k --keepParent`, `xcrun notarytool submit --keychain-profile $(NOTARY_PROFILE) --wait`,
     `xcrun stapler staple` the app, re-zip the stapled app.
  3. DMG via `hdiutil create` (app + `/Applications` symlink), sign, notarize, staple.
  4. Verify with `spctl -a -vv` and `stapler validate`.
  5. Print SHA-256 (hex for the cask, SRI for Nix).
  Outputs: `.build/release/NebulaMac-<ver>.dmg` and `NebulaMac-<ver>.zip`.
- `make publish` — `gh release create v<ver>` with both files. Run manually; never called by `release`.

`NOTARY_PROFILE` defaults to `nebulamac-notary`. The one-time `xcrun notarytool store-credentials`
step is done by the maintainer (needs an app-specific password).

Hardened runtime needs no entitlements: privileged commands run via `/usr/bin/sudo` and
`/usr/bin/osascript` subprocesses.

### Passwordless script for downloaded installs

`install-sudoers.sh` ships inside the app. Settings → Advanced shows
`"/Applications/NebulaMac.app/Contents/Resources/install-sudoers.sh"` (resolved from
`Bundle.main`). Default `--nebula` in the script is auto-detected using the same search list.

### Homebrew

`packaging/homebrew/nebulamac.rb`: cask pointing at the release zip, `depends_on formula: "nebula"`,
`depends_on macos: ">= :sonoma"`, `zap` for the app's preferences. The maintainer creates
`justinan7/homebrew-tap` and copies the file into `Casks/`. Install: `brew install --cask justinan7/tap/nebulamac`.

### Nix

`flake.nix` exposing `packages.aarch64-darwin.default` / `x86_64-darwin.default`: `fetchurl` the
release zip, unpack to `$out/Applications/NebulaMac.app`. Install:
`nix profile install github:justinan7/NebulaMac`. nixpkgs submission is out of scope.

## 3. Docs

- `README.md` — short, plain: what it is (one line, no screenshot for now),
  Install (DMG / Homebrew / Nix), Get a mesh (recommend [Nebula Commander](https://github.com/NixRTR/nebula-commander)
  for CA/certs/configs; or bring your own), Add a network (4 steps), Passwordless (optional), Build from source.
- `docs/how-it-works.md` — the current "How it works" + multi-mesh detail moved out of the README.
- `docs/RELEASING.md` — one-time setup (notary credentials, tap repo) + per-release checklist.

## Testing

- `make test` passes (existing Swift Testing suite + sudoers script tests + shellcheck).
- New `BinaryLocatorTests` (search order, missing binaries, tilde expansion).
- Sudoers script test covers the auto-detected `--nebula` default.
- Manual: Settings tabs in light and dark mode; icon renders at 16–1024 px.
- Release: `spctl -a -vv` accepts the app; `stapler validate` passes on app and DMG.

## Out of scope

Sparkle auto-update, CI signing, nixpkgs submission, App Store.
